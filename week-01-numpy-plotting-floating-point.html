    Array construction quick reference.

    Use linspace when the number of points matters and arange when the step matters. We do not emphasize np.empty because uninitialized values invite accidental use.
    🔗
    🔗

    Indexing, slicing, and vectorization.

    import numpy as np

x = np.linspace(0, 2, 9)
y = x**2 - 2
print(x[0], x[-1], y[2:6])
    Indexing selects one entry; slicing selects a view of several entries. The vectorized expression evaluates every grid point without a Python loop.
    🔗
    🔗

    A small two-dimensional iteration history.

    import numpy as np

history = np.array([
    [0, 1.000, -1.000],
    [1, 1.500,  0.250],
    [2, 1.425,  0.031],
])
iterations = history[:, 0]
approximations = history[:, 1]
residuals = history[:, 2]
    Rows represent iterations; columns represent iteration number, approximation, and residual. This compact structure anticipates tables produced by root-finding algorithms.
    🔗
    🔗

    Selected universal functions and reductions.

    Universal functions such as np.sqrt , np.sin , np.exp , and np.abs act entrywise. Reductions such as np.sum , np.mean , np.min , and np.max summarize an array. Always interpret what a reduction means mathematically.

    Line plots and scatter plots.

    import numpy as np
import matplotlib.pyplot as plt

x_plot = np.linspace(0, 2, 200)
y_plot = x_plot**2 - 2
plt.plot(x_plot, y_plot, label=r"$f(x)=x^2-2$")
plt.scatter(approximations, residuals, marker="x", color="tab:orange",
            label="iteration history")
plt.axhline(0, color="black", linewidth=1)
plt.title("Function values and root-finding trials")
plt.xlabel("x")
plt.ylabel("f(x)")
plt.legend(); plt.grid(True, alpha=0.3); plt.show()
    A line emphasizes a sampled curve; scatter emphasizes individual observations. A professional plot identifies quantities, units when applicable, and series with a descriptive title, axis labels, and legend. Use sufficient contrast plus markers or line styles so meaning never depends on color alone, and check that the scale supports the intended conclusion.

    Floating-point comparisons and accumulated roundoff.

    import numpy as np

result = 0.1 + 0.2
print(result == 0.3)
print(np.isclose(result, 0.3, rtol=1e-12, atol=1e-15))
forward = sum([0.1] * 10)
print(forward, forward - 1.0)
    np.isclose asks whether values agree within relative and absolute tolerances; tolerances must reflect scale and purpose. Repeated approximate operations can create accumulated roundoff. A tiny discrepancy may be harmless, while an unexpectedly large residual can reveal an unstable computation or bug. Exact equality is still appropriate for integers and other genuinely exact quantities.
