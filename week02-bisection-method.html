    Section 2.2 Bisection Method

    Let’s explore the bisection method, a simple and reliable technique that makes minimal assumptions about the function \(f(x)\text{.}\) This method is rooted in the Intermediate Value Theorem, a fundamental result you may recall from Calculus I. Before diving into the method itself, let’s briefly revisit the theorem:

    Theorem 2.2.1. Intermediate Value Theorem.

    If \(f\in C[a,b]\) and \(K\) is any number between \(f(a)\) and \(f(b)\text{,}\) then there exists \(c\in(a,b)\) with \(f(c)=K\text{.}\)

    🔗
    🔗

    Subsection The Method

    According to the Intermediate Value Theorem, if a continuous function \(f\) is defined on the interval \([a, b]\) and satisfies \(f(a)f(b) \lt 0\text{,}\) then there exists \(p \in [a, b]\) such that \(f(p) = 0\text{.}\) This principle forms the foundation of the bisection method. At each step, the interval \([a, b]\) is divided into two halves by computing the midpoint. The value of \(f\) is then evaluated at the midpoint, and we determine which subinterval contains the root based on the sign of the function. The subinterval that does not contain the root is discarded, and the process is repeated on the remaining interval.
    🔗

    Example 2.2.2.

    Apply the bisection method to find the root of the function
    \begin{equation*} f(x)=x^2-3 \end{equation*}
    starting from the interval \([1.73,1.735]\text{.}\) Calculate \(p_1\text{,}\) \(p_2\text{,}\) and \(p_3\text{.}\)
    🔗
    Solution.
    First, we need to verify there exist a root \(p\) in the interval \([a,b]\text{,}\) where \(a=1.73\) and \(b=1.735\text{,}\)
    \begin{align*} f(a) \amp = f(1.73)=1.73^2-3=-0.0071 \lt 0 \\ f(b) \amp = f(1.735)=1.735^2-3=0.010225 \gt 0 \end{align*}
    Since \(f(1.73)f(1.735) \lt 0\text{,}\) then there exists \(p \in [1.73, 1.735]\) such that \(f(p) = 0\text{.}\) Hence, \(p_1\) is the midpoint of the interval, that is,
    \begin{equation*} p_1 = \frac{1.73+1.735}{2} = 1.7325 \end{equation*}
    Then we evaluate the function at \(p_1\text{,}\)
    \begin{equation*} f(p_1) = f(1.7325) = 1.7325^2-3 = 0.00155625 \gt 0 \end{equation*}
    Therefore, the root \(p\) is in the left subinterval since the function has different signs at the endpoints (\(a\) and \(p_1\)) of left subinterval. Then, \(p_2\) is the midpoint of left subinterval, that is,
    \begin{equation*} p_2 = \frac{1.73+1.7325}{2} = 1.73125 \end{equation*}
    Since
    \begin{equation*} f(p_2)=f(1.73125)=1.73125^2-3=-0.0027734375 \lt 0 \end{equation*}
    the root \(p\) is between \(p_1\) and \(p_2\text{,}\) therefore,
    \begin{equation*} p_3 = \frac{1.7325+1.73125}{2} = 1.731875 \end{equation*}

    Subsection Error Analysis

    Now, let’s perform an error analysis for the bisection method to understand how accurately it approximates the root at each step.
    🔗

    Video placeholder — PANOPTO_ID required.

    Replace the sentinel ID with the assigned Panopto video before publishing.

    

    Theorem 2.2.3.

    Suppose that \(f\in C[a,b]\) and \(f(a)f(b) \lt 0\text{.}\) The bisection method generates a sequence \(\{p_{n}\}\) approximating a zero \(p\) of \(f(x)\) with
    \begin{equation*} |p_{n}-p| \leq \frac{{b-a}}{2^{n}} \end{equation*}
    🔗
    🔗

    Proof.
    Let the sequences \(\{a_{n}\}\) and \(\{b_{n}\}\) denote the left-end and right-end points of the subintervals generated by the bisection method. Since at each step the interval is halved, we have
    \begin{equation*} b_{n}-a_{n}=\frac{1}{2}(b_{n-1}-a_{n-1}) \end{equation*}
    By mathematical induction, we get
    \begin{align*} b_{n}-a_{n} \amp= \frac{1}{2}(b_{n-1}-a_{n-1}) \\ \amp= \frac{1}{2^{2}}(b_{n-2}-a_{n-2}) \\ \amp= \ldots \\ \amp= \frac{1}{2^{n-1}}(b_{1}-a_{1}) \\ \amp= \frac{1}{2^{n-1}}(b-a) \end{align*}
    Therefore,
    \begin{equation*} |p_{n}-p|\leq\frac{1}{2}(b_{n}-a_{n}) = \frac{1}{2}\frac{1}{2^{n-1}}(b-a) = \frac{{b-a}}{2^{n}} \end{equation*}
    🔗
    🔗

    Remark 2.2.4.

    The bisection method converges linearly with a rate of convergence \(C=\frac{1}{2}\) by this theorem and the definition of the Order of Convergence.
    🔗
    🔗

    Remark 2.2.5.

    The bisection method takes
    \begin{equation} n \geq \log_{2}\left(\frac{b-a}{atol}\right)\tag{2.2.1} \end{equation}
    iterations to obtain a value \(p_n\) that satisfies \(|p_{n}-p|\leq atol\text{,}\) where \(atol\) is a predefined error tolerance.
    🔗
    🔗

    Example 2.2.6.

    Let’s revisit last example of applying the bisection method to find the root of the function
    \begin{equation*} f(x) = x^2-3 \end{equation*}
    starting from the interval \([1.73,1.735]\text{.}\) If the allowed approximation tolerance is \(atol = 10^{-3}\text{,}\) how many iterations at least are required?
    🔗
    Solution.
    By (2.2.1), we have
    \begin{equation*} n \geq \log_{2}\left(\frac{b-a}{atol}\right) = \log_{2}\left(\frac{1.735-1.73}{10^{-3}}\right) = \log_{2} 5 \approx 2.32 \end{equation*}
    Therefore, it requires at least 3 iterations such that \(|p_{n}-p|\leq 10^{-3}\text{.}\)

    Remark 2.2.7.

    This example suggests that we need at least 3 iterations to achieve an error tolerance of \(|p_n - p| \leq 10^{-3}\text{.}\) We can confirm this using Example 6, where the first three approximations were computed, with \(p_3 = 1.731875\text{.}\)
    🔗
    For the simple function \(f(x) = x^2 - 3\text{,}\) the exact positive root is \(p = \sqrt{3}\text{.}\) Therefore, the absolute error at the third iteration is
    \begin{equation*} |p_3 - p| = |1.731875 - \sqrt{3}| \approx 0.000175 \lt 10^{-3}, \end{equation*}
    which verifies that the desired accuracy is indeed achieved after 3 iterations.

    Next, we’ll summarize the steps of the bisection algorithm, illustrate its process with a flowchart, and then implement it using Python code.

    

    Algorithm 2.2.8. Bisection Method.

    1. Define \(p=(a+b)/2\text{.}\)
      🔗
    2. If \(b-c\le atol\text{,}\) then accept \(p\) as the root and stop.
      🔗
    3. If \(f(b)\cdot f(p)\le 0\text{,}\) then set \(a=p\text{.}\) Otherwise, set \(b=p\text{.}\) Return to step 1.
      🔗
    🔗
    def bisection(f, a, b, atol, max_iter):
    root_found = False
    if f(a)*f(b) \le 0:
        for i in range(max_iter):
            p = (a+b)/2
            if b-p \le atol:
                root_found = True
                return p
            elif f(b)*f(p) \le 0:
                a = p
            else:
                b = p
        if not root_found:
            raise Exception(
                "Bisection did not converge "
                f"within {max_iter} iterations. "
                "Try a greater max_iter."
            )
    else:
        raise Exception(
            "Bisection is not applicable for this problem."
        )
    Let’s apply the bisection method to find a root of the function \(f(x) = x^3 + 2x^2 + 5x - 2\) within the interval \([0, 2]\text{,}\) using error tolerance of \(atol = 10^{-3}\text{.}\) We also set max_iter = 20, as we expect the method to converge to a root within 20 iterations.
    🔗
    p = bisection(
    f=lambda x: x*x*x + 2*x*x + 5*x - 2,
    a=0,
    b=2,
    atol=1e-3,
    max_iter=20,
)
print(f"The root found by bisection method is {p}.")
