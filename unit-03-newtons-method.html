    Section 3.1 Newton’s Method

    Now that we’ve explored the bisection method, let’s move on to a more powerful and faster-converging technique: Newton’s method.
    🔗

    Subsection The Method

    
    Newton’s method (also known as the Newton-Raphson method) is an iterative algorithm used to approximate the roots of a real-valued function \(f(x)\text{.}\) Unlike the bisection method, which only requires function evaluations, Newton’s method also uses the derivative \(f'(x)\) to guide each step.
    🔗
    Starting from an initial guess \(p_0\) close to the root, the method generates a sequence \(\{p_n\}\) using the formula
    \begin{equation*} p_{n+1} = p_n - \frac{f(p_n)}{f'(p_n)},\quad n = 0, 1, 2, \ldots \end{equation*}
    Geometrically, this formula corresponds to finding the \(x\)-intercept of the tangent line to the graph of \(f(x)\) at the point \((p_n, f(p_n))\text{.}\)
    🔗
    🔗
    When the initial guess is sufficiently close to the actual root and \(f'(p_n) \neq 0\text{,}\) Newton’s method typically converges very rapidly, at least quadratically, making it much more efficient than bisection for smooth functions. However, this speed comes with a trade-off: Newton’s method may fail to converge if the initial guess is poor or if \(f'(x)\) is zero or undefined during the iteration.
    🔗

    Example 3.1.3.

    Apply Newton’s method to find the root of the function
    \begin{equation*} f(x)=x^2-3 \end{equation*}
    with an initial guess \(p_0=1\text{.}\) Calculate \(p_1\text{,}\) \(p_2\text{,}\) and \(p_3\text{.}\) Round your answer to four decimal places if necessary.
    🔗
    Solution.
    It is easy to find \(f'(x)=2x\text{,}\) hence the iterative formula for Newton’s method is
    \begin{equation*} p_{n+1} = p_n - \frac{f(p_n)}{f'(p_n)}=p_n-\frac{p_n^2-3}{2p_n}. \end{equation*}
    Therefore,
    \begin{align*} p_1 \amp= p_0-\frac{p_0^2-3}{2p_0} = 1-\frac{1^2-3}{2\times 1} = 2\\ p_2 \amp= p_1-\frac{p_1^2-3}{2p_1} = 2-\frac{2^2-3}{2\times 2} = 1.75\\ p_3 \amp= p_2-\frac{p_2^2-3}{2p_2} = 1.75-\frac{1.75^2-3}{2\times 1.75} \approx 1.7321. \end{align*}

    Subsection Error Analysis

    Next, we’ll carry out an error analysis for Newton’s method. To do this, we’ll need to use Taylor series. Let’s begin by recalling the definition.

    Definition 3.1.4. Taylor Series.

    Let \(f\) be a function with derivatives of all orders throughout some interval containing \(a\) as an interior point. Then the Taylor series generated by \(f\) at \(x=a\) is
    \begin{align*} f(x) \amp= \sum_{k=0}^{\infty}\frac{f^{(k)}(a)}{k!}(x-a)^k\\ \amp= f(a)+f'(a)(x-a)+\frac{f''(a)}{2!}(x-a)^2 +\cdots+\frac{f^{(k)}(a)}{k!}(x-a)^k\\ \amp\quad+\frac{f^{(k+1)}(\xi)}{(k+1)!}(x-a)^{k+1}, \end{align*}
    where \(\xi\) is between \(x\) and \(a\text{.}\)
    🔗
    🔗
    🔗

    Theorem 3.1.5. Quadratic Convergence of Newton’s Method.

    Newton’s method has quadratic convergence.
    🔗
    🔗

    Proof.
    
    To show Newton’s method has quadratic convergence, we need to show the following inequality holds true:
    \begin{equation} |p_{n+1} - p| \leq C |p_n - p|^2.\tag{3.1.1} \end{equation}
    🔗
    Suppose \(p_n\) is sufficiently close to the root \(p\) of the function \(f\text{.}\) Then the Taylor series (choose \(k=1\)) generated by \(f\) at \(x=p_n\) is
    \begin{equation*} f(x)=f(p_n)+f'(p_n)(x-p_n)+\frac{f''(\xi)}{2!}(x-p_n)^2. \end{equation*}
    Hence,
    \begin{equation*} f(p)=f(p_n)+f'(p_n)(p-p_n)+\frac{f''(\xi)}{2!}(p-p_n)^2. \end{equation*}
    But \(p\) is the root of the function \(f\text{,}\) which means \(f(p)=0\text{.}\) Solving this equation for \(p\) yields
    \begin{equation*} p=p_n-\frac{f(p_n)}{f'(p_n)}-\frac{f''(\xi)}{2f'(p_n)}\left(p-p_n\right)^2. \end{equation*}
    🔗
    By Newton’s method, \(p_{n+1} = p_n - \frac{f(p_n)}{f'(p_n)}\text{.}\) Therefore, the left side of (3.1.1) becomes
    \begin{align*} |p_{n+1} - p| \amp= \left|\left[p_n - \frac{f(p_n)}{f'(p_n)}\right]-\left[p_n-\frac{f(p_n)}{f'(p_n)}-\frac{f''(\xi)}{2f'(p_n)}\left(p-p_n\right)^2\right]\right|\\ \amp=\left|\frac{f''(\xi)}{2f'(p_n)}\left(p-p_n\right)^2\right|\\ \amp=\left|\frac{f''(\xi)}{2f'(p_n)}\right|\left|p_n-p\right|^2. \end{align*}
    Let \(C=\max\left|\frac{f''(\xi)}{2f'(p_n)}\right|\text{.}\) Then
    \begin{equation*} |p_{n+1} - p|=\left|\frac{f''(\xi)}{2f'(p_n)}\right|\left|p_n-p\right|^2 \leq C |p_n - p|^2, \end{equation*}
    which proves the desired bound.
    🔗
    🔗
    🔗

    Subsection Algorithm and Coding

    Next, we’ll summarize the steps of Newton’s method, illustrate its process with a flowchart, and then implement it using Python code.
    🔗

    Algorithm 3.1.6. Newton’s Method.

    1. Given a scalar differentiable function \(f(x)\text{,}\) start from an initial guess \(p_0\text{.}\)
      🔗
    2. For \(n=0,1,2,\ldots\text{,}\) set
      \begin{equation*} p_{n+1} = p_n - \frac{f(p_n)}{f'(p_n)} \end{equation*}
      until \(|p_{n+1} - p_n| \leq atol\) or a maximum number of iterations is reached.
      🔗
    🔗
    
    def newton(f, fprime, p0, atol, max_iter):
    root_found = False

    for i in range(max_iter):
        p1 = p0 - f(p0)/fprime(p0)
        if abs(p1 - p0) < atol:
            root_found = True
            return p1
        else:
            p0 = p1

    if not root_found:
        raise Exception(
            f"Newton's method did not converge within {max_iter} iterations. "
            "Try different initial guesses or increase max_iter."
        )
    Let’s apply Newton’s method to find a root of the function \(f(x) = x^3 + 2x^2 + 5x - 2\) with an initial guess p0=1, using error tolerance \(atol = 10^{-3}\text{.}\) We also set max_iter = 20, as we expect the method to converge to a root within 20 iterations. We also need the derivative, which in this case is \(f'(x) = 3x^2 + 4x + 5\text{.}\)
    🔗
    p = newton(f=lambda x: x**3 + 2*x**2 + 5*x - 2,
           fprime=lambda x: 3*x**2 + 4*x + 5,
           p0=1, atol=1e-3, max_iter=20)
print(f"The root found by Newton's method is {p}.")

    Remark 3.1.8. Tips for Choosing an Initial Guess.

    A good initial guess for Newton’s method is one that is close to the actual root. To choose one:
    • Try graphing the function to visually identify where it crosses the \(x\)-axis.
      🔗
    • Look for an interval where the function changes sign (like in the bisection method), and pick a point near that change.
      🔗
    • If possible, use physical context or analytical insight to estimate where a root might be.
      🔗
    • Avoid points where the derivative \(f'(x)\) is zero or very small, as this can cause the method to diverge or behave unpredictably.
      🔗
    Starting with a reasonable guess increases the chances of fast and reliable convergence.
