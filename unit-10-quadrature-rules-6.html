    Section 10.4 Gaussian Quadrature

    
    Newton-Cotes formulas are derived by integrating interpolating polynomials based on equally spaced nodes, which simplifies the formulation of composite rules. However, equally spaced nodes are not always optimal for accuracy.
    🔗
    Gaussian quadrature aims to maximize the accuracy of the numerical quadrature rule:
    \begin{equation*} \int_a^b f(x) \, dx \approx \sum_{i=1}^n w_i f(x_i)\text{,} \end{equation*}
    by optimally selecting the nodes \(x_i\) and weights \(w_i\text{.}\) Unlike Newton-Cotes formulas, which label nodes starting from \(x_0\text{,}\) Gaussian quadrature typically starts with \(x_1\text{.}\) This notational difference is standard in the literature, as it simplifies the presentation of the corresponding theoretical equations.
    🔗

    Example 10.4.1.

    Let \((a,b)=(-1,1)\) and \(n=2\text{.}\) Find the optimal \(x_{i}\) and \(w_{i}\) for the Gaussian quadrature rule.
    🔗
    Solution.
    When \((a,b)=(-1,1)\) and \(n=2\text{,}\) the quadrature rule becomes
    \begin{equation*} \int_{-1}^1 f(x) \, dx \approx w_1f(x_1)+w_2f(x_2) \end{equation*}
    There are four parameters to determine: \(x_{1},x_{2},w_{1},w_{2}\text{.}\) We need four constraints. Let’s require the rule to integrate the following functions exactly: \(f(x)=1,f(x)=x,f(x)=x^{2}\text{,}\) and \(f(x)=x^{3}\text{.}\)
    \begin{align*} f(x)=1 :\quad \int_{-1}^1 f(x) \, dx = \int_{-1}^1 (1) \, dx = 2 \amp \quad w_1f(x_1)+w_2f(x_2) = w_1+w_2\\ \amp \Rightarrow\quad w_1+w_2 = 2\\ f(x)=x :\quad \int_{-1}^1 f(x) \, dx = \int_{-1}^1 x \, dx = 0, \amp \quad w_1f(x_1)+w_2f(x_2) = w_1x_1+w_2x_2\\ \amp \Rightarrow\quad w_1x_1+w_2x_2 = 0\\ f(x)=x^2 :\quad \int_{-1}^1 f(x) \, dx = \int_{-1}^1 x^2 \, dx = \frac{2}{3}, \amp \quad w_1f(x_1)+w_2f(x_2) = w_1x_1^2+w_2x_2^2\\ \amp \Rightarrow\quad w_1x_1^2+w_2x_2^2 = \frac{2}{3}\\ f(x)=x^3 :\quad \int_{-1}^1 f(x) \, dx = \int_{-1}^1 x^3 \, dx = 0, \amp \quad w_1f(x_1)+w_2f(x_2) = w_1x_1^3+w_2x_2^3\\ \amp \Rightarrow\quad w_1x_1^3+w_2x_2^3 = 0 \end{align*}
    Solving the equations gives: \(w_{1}=w_{2}=1,x_{1}=\frac{-\sqrt{3}}{3},x_{2}=\frac{\sqrt{3}}{3}\text{.}\) Therefore the quadrature rule is:
    \begin{equation*} \int_{-1}^{1}f(x) \, \mathrm{d}x \approx f\left(\frac{-\sqrt{3}}{3}\right)+f\left(\frac{\sqrt{3}}{3}\right) \end{equation*}

    Remark 10.4.2.

    • The two nodes are not equally spaced over the interval \((-1, 1)\text{.}\)
      🔗
      🔗
    • This quadrature rule achieves degree 3 accuracy using only two nodes. For comparison, Simpson’s rule also has degree 3 accuracy, but it requires three nodes.
      🔗
      🔗
    • In general, Gaussian quadrature achieves a degree of accuracy \(2n - 1\) using only \(n\) nodes, making it highly efficient.
      🔗
      🔗
    🔗
    🔗
    🔗
    🔗
    As you can see, even for \(n = 2\text{,}\) finding the nodes and weights manually is not straightforward. As the number of nodes increases, solving the system to determine the \(x_i\) and \(w_i\) becomes increasingly complex. The good news is that there’s a more efficient approach. The nodes \(x_i\) used in Gaussian quadrature are the roots of the Legendre polynomials, a family of orthogonal polynomials. The first few Legendre polynomials are:
    \begin{align*} L_0(x) \amp = 1\\ L_1(x) \amp = x\\ L_2(x) \amp = x^2 - \frac{1}{3}\\ L_3(x) \amp = x^3 - \frac{3}{5}x\\ L_4(x) \amp = x^4 - \frac{6}{7}x^2 + \frac{3}{35}\\ L_5(x) \amp = x^5 - \frac{10}{9}x^3 + \frac{5}{21}x \end{align*}
    You may have encountered these types of polynomials when studying the Gram-Schmidt process in Linear Algebra, as they form an orthogonal basis on \([-1, 1]\text{.}\) Once the nodes \(x_i\) are determined (as the roots of these polynomials), the corresponding weights \(w_i\) can be computed using \(w_i = \int_{-1}^1 \ell_i(x) \, dx\text{,}\) where \(\ell_i(x)\) are the Lagrange basis functions associated with the nodes \(x_i\text{.}\)
    🔗
    To summarize, the Gauss-Legendre quadrature rule for the integral of \(f\) over \((-1,1)\) is
    \begin{equation*} \int_{-1}^1 f(x) \, \mathrm{d}x = \sum_{i=1}^n w_i f(x_i) \end{equation*}
    where \(x_{1},x_{2},...,x_{n}\) are the roots of the \(n\)-th Legendre polynomial, and the weights are computed using \(w_i = \int_{-1}^1 \ell_i(x) \, \mathrm{d}x\text{.}\)
    🔗
    We can easily find the nodes and weights using roots_legendre function in Python’s Scipy module. 
    import numpy as np
from scipy.special import roots_legendre

n = 3
roots, weights = roots_legendre(n)
print("The roots are: "+", ".join([f"x{i+1} = {x}" for i, x in enumerate(roots)]))
print("The weights are: "+", ".join([f"w{i+1} = {x}" for i, x in enumerate(weights)]))

    The roots are: x1 = -0.7745966692414834, x2 = 0.0, x3 = 0.7745966692414834
The weights are: w1 = 0.5555555555555558, w2 = 0.8888888888888883, w3 = 0.5555555555555558

    Example 10.4.3.

    Approximate \(\int_{-1}^1 \cos(x) \, dx\) using Gauss-Legendre quadrature with \(n = 3\) nodes. Round both the nodes and weights to four decimal places before performing the calculation. Then, round the final result to four decimal places.
    🔗
    Solution.
    Use the nodes and weights obtained above and using four-digit rounding, we have
    \begin{equation*} \int_{-1}^1 \cos x dx \approx 0.5556 \cos (-0.7746) + 0.8889 \cos 0 + 0.5556 \cos (0.7746)=1.6831 \end{equation*}

    To integrate a function over an interval \([a, b]\) instead of \([-1, 1]\text{,}\) we use a change of variables. With the substitution
    \begin{equation*} x = \frac{b - a}{2}t + \frac{a + b}{2}\text{,} \end{equation*}
    the integral transforms as
    \begin{equation*} \int_a^b f(x) \, dx = \frac{b - a}{2} \int_{-1}^1 f\left( \frac{b - a}{2}t + \frac{a + b}{2} \right) \, dt \end{equation*}
    The right-hand side can then be approximated using Gaussian quadrature as described previously.
    🔗

    Example 10.4.4.

    Approximate \(\int_{0.5}^{1}x^x dx\) using Gauss-Legendre quadrature with \(n=4\) nodes. Round the final result to four decimal places. The nodes and weights for Gauss-Legendre quadrature rule of \(n=4\) are given as follows (rounding to four digits),
    roots \(-0.8611\) \(-0.3400\) \(0.3400\) \(0.8611\)
    weights \(0.3479\) \(0.6521\) \(0.6521\) \(0.3479\)
    🔗
    Solution.
    We need to use the substitution \(x = \frac{1 - 0.5}{2}t + \frac{1+0.5}{2}=\frac{t+3}{4}\) to transform the old integral over \([0.5,1]\) to a new integral over \([-1,1]\text{.}\)
    \begin{equation*} \int_{0.5}^{1}x^x dx=\int_{-1}^{1} \left(\frac{t+3}{4}\right)^{\frac{t+3}{4}}d\left(\frac{t+3}{4}\right)=\frac{1}{4}\int_{-1}^{1} \left(\frac{t+3}{4}\right)^{\frac{t+3}{4}}dt \end{equation*}
    For \(n=4\text{,}\)
    \begin{align*} \int_{-1}^{1} \left(\frac{t+3}{4}\right)^{\frac{t+3}{4}}dt = \amp (0.3479)\left(\frac{-0.8611+3}{4}\right)^{\frac{-0.8611+3}{4}}+(0.6521)\left(\frac{-0.3400+3}{4}\right)^{\frac{-0.3400+3}{4}}\\ \amp +(0.6521)\left(\frac{0.3400+3}{4}\right)^{\frac{0.3400+3}{4}}+(0.3479)\left(\frac{0.8611+3}{4}\right)^{\frac{0.8611+3}{4}}\\ \approx\amp 1.64326 \end{align*}
    Therefore,
    \begin{equation*} \int_{0.5}^{1}x^x dx=\frac{1}{4}\int_{-1}^{1} \left(\frac{t+3}{4}\right)^{\frac{t+3}{4}}dt = \frac{1}{4} (1.64326) \approx 0.4108 \end{equation*}
